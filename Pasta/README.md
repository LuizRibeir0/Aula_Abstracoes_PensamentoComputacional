### Situação: Enviar uma alteração e integrar ao projeto

1. Desenvolver uma funcionalidade ou correção no código
2. Criar uma branch para essa alteração
3. Fazer commit das mudanças
4. Enviar (push) a branch para o repositório remoto
5. Abrir um Pull Request
6. Aguardar a revisão do código
7. Verificar se o Pull Request foi aprovado

8. **Se não for aprovado:**
   - Fazer ajustes no código
   - Atualizar o Pull Request
   - Voltar para a etapa de revisão

9. **Se for aprovado:**
   - Realizar o merge do Pull Request

10. Finalizar processo
