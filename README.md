# 📌 Projeto: Modelagem de Algoritmo - Pull Request

## 📖 Descrição

Este projeto foi desenvolvido como parte de uma atividade acadêmica com o objetivo de aplicar conceitos de pensamento computacional na modelagem de algoritmos.

A proposta consiste em descrever, de forma estruturada, um processo do cotidiano utilizando:
- Linguagem natural (passo a passo)
- Fluxograma
- Pseudocódigo

O cenário escolhido foi o processo de criação, revisão e aprovação de um Pull Request em um ambiente de desenvolvimento de software.

---

## 🎯 Objetivo

O principal objetivo deste trabalho é exercitar a lógica de programação por meio da abstração de um processo real, transformando-o em uma sequência organizada de instruções.

Além disso, busca-se desenvolver:
- Raciocínio lógico
- Organização de ideias
- Compreensão de estruturas como condição e repetição

---

## ⚙️ Contexto

No desenvolvimento de software, especialmente utilizando plataformas como o GitHub, é comum que alterações no código sejam feitas por meio de Pull Requests.

Esse processo envolve etapas como:
1. Desenvolvimento de uma funcionalidade
2. Criação de uma branch
3. Envio das alterações
4. Abertura do Pull Request
5. Revisão do código
6. Aprovação ou solicitação de ajustes
7. Integração (merge) ao projeto principal

Esse fluxo foi utilizado como base para a construção do algoritmo.

---

## 🧠 Estruturas Utilizadas

Durante a modelagem do algoritmo, foram aplicados conceitos fundamentais de programação:

- **Sequência** → Execução ordenada de passos
- **Condição (SE/SENÃO)** → Verificação de aprovação do Pull Request
- **Repetição (ENQUANTO)** → Correção contínua até aprovação

---

## 📊 Representações do Algoritmo

O algoritmo foi representado de três formas:

- ✔️ Descrição em linguagem natural  
- ✔️ Fluxograma  
- ✔️ Pseudocódigo  

Essas diferentes formas ajudam a compreender melhor o funcionamento do processo e facilitam sua implementação em uma linguagem de programação real.

---

## 🚀 Conclusão

A atividade permitiu entender como problemas do mundo real podem ser traduzidos em algoritmos, aproximando o raciocínio humano da lógica computacional.

Esse tipo de prática é fundamental para o desenvolvimento de sistemas e para a formação na área de Engenharia de Software.
